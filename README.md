# Anderdingus

A Discord bot (AI agent) that turns live game data into natural-language answers and callouts for friend groups in voice chat. v1 targets Counter-Strike 2 via official Game State Integration (GSI).

Status: setup phase, no product code yet. See [CLAUDE.md](CLAUDE.md) for context and decisions, and `docs/decisions/` for ADRs.

The bot only reads data a player could legitimately see. It never takes game actions.

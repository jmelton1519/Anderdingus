# ADR 0005: Friend groups in Discord voice as the v1 user

Status: accepted

v1 serves small friend groups playing CS2 together in a Discord voice channel. Queries are about team state ("team economy?", "who has the bomb?"); "last known enemy position" is answered only where official data allows. This keeps the scope to private, casual play, which keeps the integrity bar (ADR 0010) easy to meet.
